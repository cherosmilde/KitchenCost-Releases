# KitchenCost Releases

Windows installers, signed updater artifacts, update manifests and release notes for KitchenCost.

Approved versions will be available on this repository's Releases page. No production release is available yet.

KitchenCost source code is maintained separately in a private repository. This repository does not grant a source-code or software licence. Use of the application is subject to its supplied licence terms.

Each stable release includes a Windows installer, its Tauri updater signature (`.sig`), and `latest.json`. Updater signatures verify the update artifact; they are separate from Windows publisher signing.

Never upload signing private keys, access tokens, customer databases, backups or licence records here.
